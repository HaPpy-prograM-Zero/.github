# happy program

- **Packs and tools:** [our store](https://plainskills.gumroad.com) — skill packs for Claude Code and plain measurement tools that check whether a result is luck. They measure results; they are not investment advice.
- **Honest status:** we test in our own projects. We promise no savings or results.
